# UDP diagnostics test report

## Environment and method

- Environment: Windows, Python 3.13.14.
- Test command: `python -m unittest discover -s tests -v`
- Scope: localhost UDP sockets only; no external hosts or SDN components.
- The suite starts and stops its local test servers as part of each test.

## Results

**8 tests passed; 0 failed** in the final run. The test runner output is
preserved in [`results\test_execution.txt`](results/test_execution.txt).
The command-line entry points were also run as separate live server and client
processes: all 3 probes were received, as recorded in
[`results\cli_localhost_results.json`](results/cli_localhost_results.json).

| Test | Result | Evidence |
|---|---|---|
| Normal client/server echo | Passed | [`results\normal_test_results.json`](results/normal_test_results.json), 2 of 2 responses |
| RTT conversion from monotonic nanoseconds | Passed | 2,500,000 ns converts to 2.5 ms |
| Dropped probe detection and JSON loss fields | Passed | [`results\packet_loss_test_results.json`](results/packet_loss_test_results.json), 1 of 3 dropped (33.33% loss) |
| Jitter calculation | Passed | Samples 10, 14, 13 ms yield 2.5 ms mean absolute difference |
| Probe count and interval configuration | Passed | [`results\configured_probes_test_results.json`](results/configured_probes_test_results.json), 3 probes at a configured 0.04-second interval |
| Malformed and out-of-range responses | Passed | Invalid datagrams ignored; valid echo is still accepted |
| Malformed server requests | Passed | Malformed JSON and oversized integer timestamps ignored; server continues echoing valid probes |
| Unavailable UDP service / timeouts | Passed | [`results\unavailable_test_results.json`](results/unavailable_test_results.json), 2 of 2 timeouts (100% loss) |
| Separate server/client CLI processes | Passed | [`results\cli_localhost_results.json`](results/cli_localhost_results.json), 3 of 3 responses |

JSON result files are generated by the tests, not hand-authored. RTT values
vary between runs because they are live localhost measurements.

An initial shell-background launch attempt did not yield responses. I repeated
the end-to-end check with the server running in a live attached process; that
run passed with 3 of 3 responses. The initial attempt is not counted as a
passing test.
